# Third-party notices

`@genii-foundation/publisher` does not bundle third-party runtime code.

Its exact GENII Publisher schema and content dependencies are separate CPAL 1.0 packages with their own source, licenses, changes, disclosures, and third-party notices. Package consumers receive those dependencies as separate installed packages.

Development and release tooling remains subject to the licenses published by its package authors. Those tools are not part of the application package runtime.
